## 速记列表与编辑

- 速记底部入口打开笔记库。顶部显示「速记」、文档数、搜索和更多菜单。列表以圆角分组显示标题、更新时间和正文摘要，支持「置顶 / 其他速记」。搜索在本机查标题和正文，显示命中摘要。导入 Markdown 或配套 ZIP、速记备份和恢复放进右上角菜单。右下角「＋」直接进入新建速记。
- 新建、导入后阅读、修改已有速记共用一个文档页面。文档默认可读，点正文区块或铅笔在原位置编辑。新建时直接把焦点放到标题或首段。保留目录、代码复制、预览和 AI 学习助手。编辑工具栏提供段落、标题、列表、待办和代码块。保存前可切换预览，离开时对未保存修改给出提示。
- 正文仍以 Markdown 存储。正文编辑使用常用区块的可视编辑，用户可直接输入文字、改标题层级或勾选待办。现有表格、嵌套语法和其他复杂内容沿用渲染器，可在对应区块展开编辑原文。局部修改只替换目标 Markdown 片段。导入的表格、图片路径、代码围栏、换行和未改动的 Markdown 保留。
- 新建内容保存在应用内，无需先选文件。空草稿离开后不出现在列表。编辑草稿按文档 ID 和读取时版本绑定，保存错误时留在当前文档。通知跳转、系统返回、速记原文入口和切文档都要处理草稿。能保存已提交的内容后才刷新阅读位置、摘要和目录。

## 已确定的 AI 行为

- **旧讨论按原文版本判断。** 文档存在且 hash 与会话匹配时，旧版讨论可继续追问，旧请求重试使用其原始快照。改正文后，绑定旧 hash 的讨论只读并提示新建讨论。仅改显示标题、置顶、阅读位置、原样保存时不会让会话只读。文档移除后仍可查看历史。
- **模拟考试沿用原限制。** 正在考试的题目页隐藏吉祥物和 AI 讨论入口。普通练习和编程沿用 Grok 的菜单接线，改用本项目的吉祥物素材。点击入口打开菜单，选择操作才触发相应请求。
- **查阅按问题需要触发。** 保留当前摘录问答作为默认可用路径。明确需要查原文、对照章节或现有摘录不足时，支持工具的模型可在当前文档使用只读工具。只写 UDP 时问 TCP 仍能得到通用知识回答，并区分原文证据与补充。

### 速记

- **列表**（`QuickNotesScreen.kt`）
  - 顶部是大标题「速记」和文档数，右侧是搜索和 ⋯ 菜单。导入 Markdown 或配套 ZIP、导出速记备份、恢复速记备份都放进 ⋯ 菜单。

- **同页编辑**（`QuickNoteEditor.kt` + `QuickNoteBlocks.kt`）
  - 新建和修改共用一个文档页。阅读页的铅笔从当前读到的标题处开始编辑；新建时焦点直接放在标题。
  - 段落、ATX 标题、单行列表项、待办和围栏代码块就地编辑。表格、引用、图片、HTML、嵌套或多行列表项保留原文，可以展开后编辑原文。
  - 工具栏提供段落、标题、列表、待办、代码块和删除。前四种把当前块转换为该类型，代码块在当前块之后插入。
  - 保存前可以切换预览。离开时如有改动，提示「保存 / 放弃修改 / 继续编辑」；空的新速记直接退出，不留下任何记录。

- **草稿**（`QuickNotesStateHolder.draft`）
  - 全局只有一份草稿，绑定文档 ID 和读取时的版本。

  - 另一份速记有未保存修改时，拒绝开始编辑新文档，不会覆盖原草稿。
  - 版本不符时保存失败，留在编辑页，文字和原因都保留。
  - 保存成功后重新打开文档，阅读位置、摘要和目录随存储内容刷新。
- 文档页和新建页隐藏底栏。
