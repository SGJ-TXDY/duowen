CodeDraftSaveUiTest 12 项。编辑器部分（3 项，第一部分已有）：只报告文字变化、光标保持、Tab 缩进、禁用态。真实 ViewModel 部分（9 项）使用 GPT 的 internal 接缝 `codeDrafts.persistence.beforeWrite`（挂起或抛错）与 `beforeBoundary`（停在排他边界），写入计数在 `beforeWrite` 中统计实际写事务：

1. 连续输入显示“草稿保存中…”，保存中仍可编辑；落盘后“草稿已保存到本机”，数据库为最新文字；之后纯光标/选区移动不改变状态、不增加写入。
2. 写入失败：持续显示“草稿保存失败，最新文字尚未保存”，文字与可编辑性保持；“重试保存”后已保存，数据库为最新文字，失败提示消失。
3. 输入后立即点“下一题”：等待期间编辑器冻结、下一题按钮禁用，落盘后才切题；系统返回同样等待落盘后回首页。
4. 保存失败时返回：弹“草稿保存失败，暂未离开”，“留在本页”保留文字；从“打开全局标签”离开同样被拦下，对话框“重试保存”成功后继续到便签页。
5. 等待离开时通知把页面设为复习页，写入在下一帧前返回（暂停帧时钟固定顺序）：成功与失败两种都保持复习页、无旧对话框；失败情况下回到题目可见失败并可重试保存。
6. 备份停在排他边界时：两处“正在备份、恢复或重置学习数据，代码和笔记暂时不能修改。”，代码编辑器与自动保存笔记不可编辑，“保存代码与笔记”禁用；边界结束后恢复编辑，备份文件包含边界前受理的最新草稿。
7. 普通客观题手动笔记：未点“保存笔记”前显示“笔记有未保存的修改……”，状态 Inactive、不显示已保存、数据库未写；点保存后“草稿已保存到本机”；再改又回到“未保存的修改”。
8. 320×480dp + 字体缩放 1.6：失败提示可见、带 liveRegion，重试按钮可见可点。

## 设备检查步骤（真机，尚未执行）

1. 编程题输入一段长代码（≥200 行，持续输入 10 秒以上），观察输入是否卡顿、“草稿保存中…/已保存到本机”是否随停顿切换；记录系统输入法下中文/英文组合输入、选词、光标拖动和 Tab 缩进是否被打断。
2. 输入后立即点下一题、返回、系统返回手势、打开全局标签：应短暂停留后离开，回到该题文字完整。
3. 飞行模式无影响（本地存储）；如能模拟存储写满，确认失败提示常驻、点“重试保存”后恢复，离开被拦并提示。
4. 输入后立刻切到后台（Home 键），等待 3 秒后从最近任务划掉应用，重新打开：最后文字应已保存（onStop 已强制提交合并窗口；立即强杀不作保证）。
5. 设置中导出完整备份时尝试编辑：编辑器只读并显示说明，备份结束后可继续；恢复备份/重置复习进度后代码与笔记符合预期（重置保留）。
6. 普通客观题笔记：输入不点保存时显示“未保存的修改”，点保存后显示已保存。
7. 大字号、深色模式、TalkBack：失败提示会被主动朗读，重试按钮可达。
